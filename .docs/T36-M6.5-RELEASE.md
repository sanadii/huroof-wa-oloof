# T36 M6.5 public release integration

This branch integrates the reviewed T36 premium mechanics source closure from
the accepted application history. Challenge delivery remains disabled by
default: public flags are not enabled by this change, and QA admission remains
server-authorized.

## Included scope

- Challenge runtime, role-safe projections, Firebase/local adapters, and game
  routes.
- Callable authority, QA permit contract, exact map-variant commitment checks,
  server definition repository, and Firestore projection rules.
- Synthetic unit and UI coverage for challenge submission and projection
  masking.

The backend selection repair is source-equivalent to the accepted functions
package manifest `c535391ed95f2a79b60bf3551b3da8a246a56417952e8fce8629dd2c5f9b1b21`.
The client source is reconciled against the reviewed 838-file client snapshot
whose parent manifest is `c2e687a5632b2fc59ebce761716ca6d3ff748874fcd4fd60a2da974152378f1f`.

## Deliberate exclusions

No `output/` evidence, content inputs, private definitions, source-derived
fixtures, media registries, credentials, generated deployment packages, or
database publication inputs are versioned here. The two source-derived M4/M5
fixtures are replaced by synthetic UI data. Tests needing excluded private
media are explicitly skipped in this public checkout.

The reviewed snapshot is preserved so the older GitHub base cannot roll back
current production UI or catalog behavior. The final selector repair is the
sole client-source difference from that snapshot.

## Reproduction

Use Node 22.23.2 and the committed lockfiles. Run `npm run build`,
`npm --prefix functions test`, and the focused game/UI checks recorded in the
release handoff. A Vercel upload candidate is derived only from the resulting
static `dist/` directory; deployment, Firebase publishing, and flag changes
are out of scope for this branch.
